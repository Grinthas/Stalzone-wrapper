# Stalzone Wrapper

Подставляет оптимизированные JVM-флаги при запуске Java-клиента Stalzone.
Работает через IFEO hook Windows в режиме фильтра по полному пути, поэтому
перехватывается только Java игры, а не все Java-программы на компьютере.

## Сборка

```
GOOS=windows GOARCH=amd64 go build -ldflags="-s -w -H windowsgui" -o "dist/Stalzone Wrapper.exe" ./cmd/gui
GOOS=windows GOARCH=amd64 go build -ldflags="-s -w -H windowsgui" -o dist/service.exe ./cmd/service
```

## Использование

1. Положите `Stalzone Wrapper.exe` и `service.exe` в одну постоянную папку.
2. Запустите `Stalzone Wrapper.exe` (при необходимости — «Перезапустить от администратора»).
3. На «Главной» нажмите «Установить». Hook ставится на exe игры — `stalzone.exe` (лаунчер)
   и `stalzonew.exe` (Steam), как в EXBO-Community/stalcraft-jvm-optimization. Путь к игре не нужен.
   Hook предыдущих версий на `java.exe` удаляется автоматически.
4. На вкладке «Профили» выберите `low`, `balanced` или `high` (создаются под ваш ПК в `configs/`).
   Можно положить свой JSON-профиль (пример: `examples/aikar.json`).
5. На вкладке «Оптимизация» wrapper определяет процессор, память и видеокарту, создаёт профиль `auto`
   под ваш ПК и может на время игры повышать приоритет, включать схему питания
   «Высокая производительность» и выбирать дискретную видеокарту.
6. На вкладке «Память» можно освободить оперативную память (как Mem Reduct) вручную
   или включить автоочистку при превышении порога. Процессы игры не затрагиваются.
7. На вкладке «Сервер» можно выбрать узел подключения (туннель) для каждого региона:
   загрузить список, проверить пинг и выбрать лучший. «Выбор игры» сбрасывает настройку.
8. Запустите игру. Что было передано в Java — на вкладке «Журнал».

Требуется Windows 10 1607+ и WebView2 Runtime (есть в Windows 10/11 по умолчанию).

## Если игра не запускается

Ошибка лаунчера «Failed to run game process — Не удаётся найти указанный файл (os error 2)»
значит, что Windows не нашла `service.exe` по пути из hook: его удалил антивирус,
папку перенесли или программу запускали прямо из архива.

1. Распакуйте архив в постоянную папку и добавьте её в исключения антивируса.
2. Откройте `Stalzone Wrapper.exe` — у hook будет пометка «ошибка» и кнопка «Исправить».
3. Чтобы просто вернуть игру как было, нажмите «Удалить» у hook.

## Как работает

`service.exe` получает исходную команду запуска, убирает из JVM-части `-Xmx`, `-Xms` и `-XX:*`,
добавляет флаги профиля и запускает настоящую Java (обходя повторный вызов IFEO).
Аргументы самой игры после главного класса / `-jar` не трогаются.

## Участие в разработке

Проект открытый, pull request'ы и issues приветствуются. Перед отправкой:

```
gofmt -l .
GOOS=windows go vet ./...
go test ./internal/jvm/ ./internal/tunnel/ ./internal/config/
```

Wrapper не изменяет файлы игры и не обходит её защиту: он только меняет флаги JVM
при запуске Java. Не добавляйте в него ничего, что нарушает правила игры.

## Благодарности

Способ установки (hook на `stalzone.exe`/`stalzonew.exe`), запуск игры через `NtCreateUserProcess`
с пропуском IFEO, протокол списка узлов и проверки задержки, а также параметр `-Droxy_address_override`
взяты из MIT-проекта [EXBO-Community/stalcraft-jvm-optimization](https://github.com/EXBO-Community/stalcraft-jvm-optimization).
